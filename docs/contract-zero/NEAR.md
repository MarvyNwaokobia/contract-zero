# NEAR integration

CONTRACT ZERO settles its economy on **NEAR testnet** through one contract, **CZ World** ([`contracts-near/cz-world`](../../contracts-near/cz-world)).

## Accounts

| Account | Role |
|---|---|
| `contract-zero.testnet` | parent; created and funded the others |
| **`world.contract-zero.testnet`** | **the CZ World contract** |
| `server.contract-zero.testnet` | the game server, and the contract's owner. Settles raids, applies flows, registers accounts |
| `vanguard.contract-zero.testnet` | the Vanguard commander (registered as a faction) |
| `vex.contract-zero.testnet` | the Vex merchant (registered as a merchant) |

**Deployed code hash:** `HxvyoNhFAsQoNjJxBkrgmcxrbp5WBTG6EVa3xskbUWd2`. It matches the SHA-256 (base58) of the local `cargo near build non-reproducible-wasm` output, 224,375 bytes.

## Keys

No key is in the repository.

- **Full-access keys** for each account stay in the CLI's `~/.near-credentials`, mode 600. They're used only for account administration.
- **The running game** uses one function-call key per actor, restricted to `world.contract-zero.testnet` and to that actor's methods. These live in `~/.contract-zero/keys` (mode 600). They were generated by `scripts/near-keygen.mjs`, which prints only the public key.

| Account | Function-call key | Allowed methods | Gas allowance |
|---|---|---|---|
| server | `ed25519:63JU9yrWXu8GJ45KAvbeyBvRaWAQZKwToxMYJZKtugvJ` | `register_actor`, `register_player`, `settle_raid`, `apply_flows` | 0.5 NEAR |
| vanguard | `ed25519:DQ1omLD8bW9pvauMvF4KrzZi2bePFwjZ1KMa4htYd8ph` | `accept_offer` | 0.25 NEAR |
| vex | `ed25519:3aKQe7hqoKNcdfuyjCvCgQZuPfTy6k721JfyRDr6JLKD` | `post_offer`, `cancel_offer` | 0.25 NEAR |

Function-call keys can't attach a deposit, and every NEP-245 transfer needs 1 yoctoNEAR. So even a leaked agent key can't move tokens directly. The LLM planner never sees a key: it proposes, the engine validates, and the server signs with the actor's restricted key.

## Rebuild and redeploy

```bash
cd contracts-near/cz-world
cargo test                                   # 49 unit tests
cargo near build non-reproducible-wasm       # target/near/cz_world.wasm
near contract deploy world.contract-zero.testnet use-file target/near/cz_world.wasm \
  without-init-call network-config testnet sign-with-legacy-keychain send
```
